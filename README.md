# Proyecto Django CRUD 

Este proyecto es una aplicación web de gestión de tareas desarrollada con Django. Fue creado con el objetivo de mejorar mis habilidades en el desarrollo web utilizando este potente framework de Python.

## Funcionalidades

- **Registro y Autenticación de Usuarios**: Permite a los usuarios registrarse, iniciar sesión y cerrar sesión de manera segura.
- **Gestión de Tareas**: Los usuarios pueden crear, visualizar, actualizar y eliminar tareas.
- **Filtrado de Tareas**: Las tareas se pueden filtrar por estado (completadas o pendientes).
- **Interfaz de Usuario Intuitiva**: La aplicación cuenta con una interfaz amigable y fácil de usar.

## Tecnologías Utilizadas

- **Django**: Framework principal para el desarrollo del backend.
- **HTML/CSS - Bootstrap**: Para la estructura y el diseño de las páginas.
- **Postgres**: Base de datos utilizada para almacenar la información de las tareas y los usuarios.

Este proyecto me permitió profundizar en el uso de Django y mejorar mis habilidades en el desarrollo de aplicaciones web completas.
